# ❤️ Heart Fluid Particle Animation

A lightweight, interactive heart animation built with **HTML5 Canvas, CSS, and vanilla JavaScript**. Hundreds of glowing particles flow together to form a heart on a full-screen black background.

## 🌐 Live Demo

[Open Heart Animation](https://nationvk.github.io/Heart-/)

> If the page does not open yet, enable **GitHub Pages** for this repository: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. The live link will become available after GitHub Pages finishes publishing.

## ✨ Features

- **Fluid particle heart** — particles move into position to create a glowing heart shape.
- **12 colour palettes** — rainbow, red, green, blue, monochrome, yellow, purple, cyan, magenta, orange, pink, and lime.
- **Touch interaction** — press and hold anywhere on the screen to pull particles toward your finger.
- **Mouse interaction** — the same interaction works on desktop.
- **Double-tap colour change** — double-tap the screen to switch to the next colour palette.
- **Responsive canvas** — adapts when the browser window changes size.
- **No installation required** — runs directly in a modern web browser.

## 🕹️ How to Use

| Action | Result |
|---|---|
| Open the page | Starts the heart animation |
| Press and hold / click and hold | Pulls nearby particles toward the pointer |
| Double-tap the screen | Changes the colour palette |
| Resize the browser | Recalculates the heart canvas |

## 🚀 Run Locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Enjoy the animation.

No build tools, package installation, or server setup are required.
